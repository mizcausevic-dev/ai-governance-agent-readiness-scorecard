# Security Policy

`ai-governance-agent-readiness-scorecard` includes an offline analyzer, CLI, and public synthetic executive dashboard for AI governance posture. It does **not** store tenant credentials, perform live vendor fetches, or expose authenticated write paths.

## Reporting a vulnerability

- [Open a security advisory](https://github.com/mizcausevic-dev/ai-governance-agent-readiness-scorecard/security/advisories/new)

If you need to share reproduction steps privately before filing an advisory, use the contact path already published on the main Kinetic Gain surfaces and avoid including secrets or real customer data.
